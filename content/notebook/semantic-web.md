# Semantic Web

Siehe: [[Informationstechnik]]

Vision von Tim Berners-Lee (ca. 2001) – Beschreibt eine Erweiterung des [[Internet|Internets]], die es Computern ermöglicht, Informationen besser zu verstehen und zu verarbeiten, indem Daten mit **maschinenlesbaren Metadaten** angereichert werden, die ihre Bedeutung und Beziehungen beschreiben. Das ermöglicht eine effizientere Suche (siehe: [[Search Engines]]), [[Automatisierung|automatisierte]] Datenintegration und die Entwicklung intelligenterer Anwendungen im Web (siehe: [[Web Development]]).

Technische Grundlagen:
- **[[RDF]]** (Resource Description Framework) – Grundmodell, um Aussagen als *Subjekt-Prädikat-Objekt*-Tripel auszudrücken (z.B. "Diese Seite - Autor - Max Mustermann")
- **OWL** (Web Ontology Language) – zum Definieren von [[Ontologie|Ontologien]]/Klassenhierarchien und Beziehungen zwischen Konzepten
- **SPARQL** – Abfragesprache für RDF-Daten, ähnlich wie [[SQL]] für relationale Datenbanken

In der Praxis hat sich die Vision nie vollständig durchgesetzt (zu komplex, zu wenig Anreiz für Websitebetreiber) – stattdessen etablierten sich pragmatischere Teillösungen wie [[Microformats]], [[Microdata]] und [[RDFa]], die direkt in [[HTML]] eingebettet werden. Ein sichtbarer, kommerziell erfolgreicher Ableger davon ist [Schema.org](https://schema.org/) (2011, gemeinsam von Google, Microsoft, Yahoo, Yandex initiiert), das Suchmaschinen strukturierte Daten liefert.
