# Fail State ← Obstacles – Actions → Win State

Siehe: [[Game Design]]

Ein simples [[Mentale Modelle|Modell]], dass dabei helfen kann, eine vage Game Idee zu konkretisieren und die einzelnen [[Game Mechaniken]] auszuarbeiten:

1. Was ist der *Win State*?
2. Was sind die *Hindernisse*, die den Spieler vom Win State fernhalten?
3. Was ist der *Fail State*, zu dem die Hindernisse den Spieler pushen?
4. Was sind die *Aktionen* (“Verben”), mit denen der Spieler die Hindernisse überkommen & zum Win State gelangen kann?
